# CircuitFabric 实施计划

[English](implementation-plan.md)

## 交付策略

在扩展 EDA 写入或加入更多智能体运行时前，先构建确定性的语义与验证基础。每一阶段都必须保留可用的只读路径，不能仅因为后端 API 返回成功就宣称写入成功。

## 阶段 0 — 契约与仓库基础

交付：

- Logical Circuit IR、补丁、差异、证据、约束、物化计划/结果和验证报告的版本化 schema；
- 面向智能体运行时和 EDA 后端的声明式插件 manifest schema；
- 仓库工具、测试夹具策略、格式化和对密钥安全的本地配置。

验收：

- 契约示例可通过校验并保留向后版本化；
- 插件发现无需执行插件代码即可校验 manifest；
- Git 不跟踪密钥或生成状态。

## 阶段 1 — 不可变快照存储与确定性校验

交付：

- 带父级谱系的内容寻址快照存储；
- 规范化序列化，以及相互独立的 `logicalHash` / `physicalHash`；
- Schema、身份和拓扑校验器；
- IR 差异生成和保留来源信息的证据引用。

验收：

- 导入同一夹具产生相同快照哈希；
- 仅物理编辑保持 `logicalHash` 不变；
- 无效 pin/net 引用确定性失败；
- 缺失观测产生 `inconclusive`，而不是 `passed`。

## 阶段 2 — 硬件文档服务

交付：

- 已授权来源登记与安全扫描器；
- 带内容哈希与引用的 PDF/文本/BOM/网表摄入；
- 按来源关键字检索和证据包；
- 文档版本与来源信任度元数据；
- 为 EDA 发起的智能体会话提供项目范围文档检索，并将引用持久化到会话审计记录。

验收：

- 智能体只能检索已索引且获授权的内容；
- 每个返回的电气参数都带文档定位符和内容哈希；
- 文档更新以可预测的方式使派生证据包失效；
- EDA 会话只能使用其项目的已授权文档，并且每个文档派生回答保留来源定位符。

## 阶段 3 — 嘉立创已观测设计导入器

交付：

- 只读的嘉立创 bridge 插件；
- EDA 本地 bridge 面板：对话、当前设计上下文采集、任务进度和项目范围文档检索；
- 元件、引脚、导线、网络、总线、文档、DRC/ERC 和画布观测导入；
- 外部对象身份映射与能力报告；
- API/版本差异的夹具矩阵。

验收：

- 固定的嘉立创原理图产生稳定的观测快照；
- 不完整 API 字段保持明确的未知/`inconclusive`；
- 导入的图元 ID 是外部引用，而不是逻辑标识；
- 截图是证据，不能取代拓扑事实；
- bridge 不保存 API Key，并将运行时、MCP/技能和文档策略委托给 CircuitFabric。

## 阶段 4 — 融合、ChangeSet 与安全物化

交付：

- 基线/目标/回读协调；
- 将语义 IR 补丁转换为可审阅的 ChangeSet；
- 嘉立创 `preview`、`apply`、`readback` 和补偿/回滚实现；
- 前置条件检查和结构化验证报告。

验收：

- 设计漂移会拒绝过期计划；
- 部分失败停止剩余不安全操作，并报告补偿结果；
- 写入成功、回读成功和验证成功始终分别可见；
- 已知 bridge 回读延迟可标为 `inconclusive`，不得错误回滚已确认写入。

## 阶段 5 — 外部智能体运行时 Host

交付：

- Codex App Server 适配器：流式输出、动态工具、Token 用量、取消和线程映射；
- 桌面控制面工作流：项目、文档、EDA bridge 健康、运行时/API Key 引用、MCP/技能授权、会话审计、任务状态、用量、语义查询和 BOM 导出；
- 运行时中立的任务事件协议和有界工具上下文；
- 按进程和项目隔离的提供方配置；
- Claude Code/DSH 适配器的桩实现一致性夹具。

验收：

- 智能体可检查文档和观测 IR、提出 `IRPatch` 并请求获准工具；
- 智能体文本无法绕过审批或物化策略；
- 运行时重启可仅使用已存储的引用和快照恢复任务。

## 阶段 6 — 更多 EDA 与工程插件

交付：

- 第二个后端来证明可移植性，优先 KiCad 的只读导入；
- BOM、网表和 SPICE 导入/导出插件；
- 插件生命周期、签名/信任策略、健康报告、权限和隔离。

验收：

- 从两个后端导入的等价逻辑电路可协调为可比较的拓扑；
- 插件不能访问另一插件的凭据或任意项目文件；
- 每项能力均被声明、授予、审计且可撤销。

## 阶段 7 — 产品工作流与评估

交付：

- IR 差异、文档证据、ChangeSet、验证和回滚的审阅 UI；
- 可复用的参考电路与数据手册审阅工作流；
- 用于拓扑正确性、文档引用质量、写入安全和可读性的夹具语料与评估。

验收：

- 用户无需阅读原始模型推理即可理解计划变更；
- 回归可对固定的电气和视觉测试设计进行度量；
- 不支持的断言和不可验证写入会被清楚呈现。
